# 📝 Post Management App

A simple frontend blog post management app built with React and styled using Tailwind CSS. The design is based on a Figma mockup, and the app is currently hosted on Vercel.

## 🔗 Live Demo & Resources

- 🌐 Live Site: [https://post-management-app-eight.vercel.app](https://post-management-app-eight.vercel.app)
- 🎨 Figma Design: [Figma Prototype](https://www.figma.com/design/gItIKRHEYVciOV3SkFux8j/Blog-app?m=auto&t=pJi0jBswl0gHSDff-6)


## 🚀 Features

- View list of blog posts
- Create, edit, and delete blog posts
- Basic user interface with Figma-based layout
- Built using React and Tailwind CSS

> ⚠️ Note: This project is **frontend only**. There is **no backend** or persistent data storage. It is also currently **responsive** on mobile or tablet screens.
